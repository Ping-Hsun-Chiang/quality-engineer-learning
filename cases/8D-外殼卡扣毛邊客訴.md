## D2 問題描述

### 5W2H

| 項目 | 內容 |
|---|---|
| What | 外殼內側第 3 號卡扣分模線毛邊，高度 0.08～0.15 mm（規格 ≤ 0.05 mm） |
| Who | A 公司組裝線作業員 |
| Where | A 公司組裝站；外殼內側第 3 號卡扣（位於分模面邊緣） |
| When | 2026/10/05 發現；不良品來自批號 L260920 之後 |
| Why | 毛邊造成卡扣與機身干涉，無法扣合，違反圖面規格 |
| How | 組裝時卡扣卡不上，拆解後發現毛邊 |
| How many | A 公司抽查 500 件，**21 件不良（4.2%）** |

### IS / IS NOT 分析

| | IS（是） | IS NOT（不是） | 差異點 |
|---|---|---|---|
| 產品 | X100 外殼 | 其他產品 | |
| 缺點 | 毛邊 | 縮水、刮傷 | 毛邊與**鎖模力**有關 |
| 機台 | **B 機** | A 機 | 只有 B 機生產的批有問題 |
| 時間 | **9/20 之後**生產的批 | 9/20 之前 | 9/20 前後 B 機有什麼改變？ |
| 位置 | 第 3 號卡扣 | 其他 7 個卡扣 | 第 3 號卡扣在分模面邊緣，鎖模力不足時最先溢料 |

**關鍵線索**：9/20 因為 X100 訂單增加，**X100 從只在 A 機生產，擴充到 B 機也一起生產**。B 機之前生產的是較小的零件，所需鎖模力較低。

## D4 根本原因分析

### 發生原因：為什麼會產生毛邊？

**魚骨圖**（可能原因）：

| 類別 | 可能原因 | 驗證結果 |
|---|---|---|
| 人 | 調機人員未依 SOP 設定參數 | ❌ 參數紀錄與 SOP 一致 |
| 機 | **鎖模力不足** | ✅ **實測鎖模力只有設定值的 85%** |
| 機 | 模具分模面磨損 | ❌ 同一副模具在 A 機生產無毛邊 |
| 料 | 塑料批號不同、流動性變大 | ❌ A、B 機使用同一批料 |
| 法 | 射出壓力設定過高 | ❌ A、B 機參數相同 |
| 環 | 模溫異常 | ❌ 模溫紀錄正常 |

**5Why**：

| | 問題 | 回答 | 證據 |
|---|---|---|---|
| Why 1 | 為什麼第 3 號卡扣有毛邊？ | 分模面在射出時被撐開，塑料溢出 | 毛邊位置在分模線上 |
| Why 2 | 為什麼分模面被撐開？ | B 機鎖模力不足（設定值的 85%） | 鎖模力感測器實測 |
| Why 3 | 為什麼鎖模力不足？ | 液壓缸油封磨損，液壓油內洩，壓力無法維持 | 拆解檢查，油封有明顯磨耗 |
| Why 4 | 為什麼油封磨損沒有被發現？ | 保養計畫沒有包含油封檢查與鎖模力實測 | 保養計畫文件 |
| Why 5 | 為什麼之前沒有出問題？ | B 機之前生產小零件，所需鎖模力較低，85% 仍足夠；換成 X100 後才不足 | 兩種產品的鎖模力需求比較 |

**根本原因驗證（開關驗證）**：

| 條件 | 鎖模力 | 試模 100 件的毛邊數 |
|---|---|---|
| 原狀（油封磨損） | 85% | 4 件 |
| **更換油封後** | 100% | **0 件** |
| 更換油封後，刻意將鎖模力降到 85% | 85% | **5 件（問題重現）** |

→ **確認發生原因：B 機油封磨損，導致鎖模力不足。**

### 流出原因：為什麼沒被抓到？

| 檢驗站 | 現況 | 為什麼沒抓到 |
|---|---|---|
| 首件檢驗 | 只量關鍵尺寸 | 沒有檢查卡扣毛邊 |
| IPQC 巡檢 | 每 4 小時目視外觀 | 只看**外側**外觀面；卡扣在**內側** |
| OQC | 依 AQL 0.65 抽樣目視 | 檢驗規範沒有定義卡扣毛邊的**檢查方法**（只寫「無毛邊」），0.1 mm 的毛邊目視難以判斷 |

→ **確認流出原因：檢驗規範未定義內側卡扣毛邊的檢查位置與方法（缺少量具與限度樣品）。**

### 系統原因：為什麼管理系統允許這個問題發生？

1. **4M 變更管理不完整**：X100 從 A 機擴充到 B 機屬於**製程變更（換機台）**，但沒有執行變更驗證（試產、首件全尺寸、製程能力確認），也沒有通知客戶
2. **保養計畫未依實際狀況更新**：照設備原廠手冊制定，未納入關鍵部件（油封）與性能實測（鎖模力）

## D5 永久對策（10/12 提出，經小批量驗證）

| 原因類型 | 根本原因 | 永久對策 | 對策強度 | 負責 | 預計完成 |
|---|---|---|---|---|---|
| 發生 | B 機油封磨損 | 更換 B 機液壓缸油封 | 消除原因 | 設備 | 10/08 ✅ |
| 發生 | 鎖模力不足無法及時發現 | B 機加裝**鎖模力監控**，低於設定值 95% 時**自動警報並停機** | 自動偵測 | 設備 | 10/25 |
| 流出 | 檢驗規範未定義檢查方法 | 首件、IPQC、OQC 增加「卡扣毛邊」項目，用 **0.05 mm 塞規**檢查，並製作限度樣品 | 加強檢驗 | 品保 | 10/15 |
| 系統 | 換機台未做變更驗證 | 修訂 4M 變更管理程序：**換機台生產需經試產、全尺寸檢驗、Cpk 確認，並通知客戶** | 制度 | 品保 | 10/31 |
| 系統 | 保養計畫未涵蓋關鍵部件 | 保養計畫增加**油封每季檢查**、**鎖模力每月實測** | 制度 | 設備 | 10/31 |

**驗證**：10/09～10/11 於 B 機小批量試產 3,000 件，卡扣毛邊 **0 件**，且其他尺寸與外觀無異常（無副作用）。

### 執行狀況

所有對策於 10/31 前完成。B 機於 10/12 恢復生產 X100。

### 效果確認

| 指標 | 改善前（9/20～10/05） | 改善後（10/12～11/15） |
|---|---|---|
| B 機卡扣毛邊不良率 | 4.2% | **0%**（生產 52,000 件） |

- 取消 OQC 卡扣毛邊**全檢**，改為依新檢驗規範**抽檢**
- 取消綠色圓點標籤

## D7 預防再發生

### 標準化

| 文件 | 修訂內容 |
|---|---|
| 4M 變更管理程序 | 換機台、換模具、換料生產時，需完成變更驗證並通知客戶 |
| 設備保養計畫 | 所有射出機增加油封季檢、鎖模力月測 |
| 檢驗規範 X100 | 增加卡扣毛邊檢查位置、量具（塞規）與限度樣品 |
| **PFMEA** | 新增失效模式「鎖模力不足 → 毛邊」，並更新偵測方式為鎖模力監控 |
| **管制計畫** | 新增管制項目「鎖模力」：自動監控，低於 95% 停機 |

### 水平展開

| 對象 | 檢查內容 | 結果 |
|---|---|---|
| 同型號射出機 C 機、D 機 | 油封檢查、鎖模力實測 | C 機正常；**D 機鎖模力 92%，已預防性更換油封** |
| 其他有卡扣設計的產品（3 個料號） | 檢驗規範是否涵蓋卡扣毛邊 | 已全部補上 |
| 二廠射出課 | 分享本案經驗，比照修訂保養計畫 | 11/15 完成 |

### 經驗分享

本案列入 Lessons Learned 資料庫，新產品開發時要確認：
- 卡扣、分模面邊緣等易產生毛邊的位置，是否已納入檢驗規範
- 產品轉移機台生產時，是否確認新機台的鎖模力足夠

## 回顧：這份 8D 做對了什麼？

| 重點 | 本案的做法 |
|---|---|
| 問題描述具體 | 5W2H 量化，IS / IS NOT 直接指出「B 機、9/20 之後」 |
| 圍堵範圍完整 | 涵蓋在製品、庫存、在途、客戶端，並確認 A 機的批沒有問題 |
| 根因有驗證 | 開關驗證：更換油封問題消失，降低鎖模力問題重現 |
| 發生與流出都有找 | 發生：油封磨損；流出：檢驗規範缺漏；再加上系統原因 |
| 對策不只靠人 | 鎖模力自動監控停機，而不是「請作業員注意」 |
| 效果用數據證明 | 不良率 4.2% → 0%，鎖模力 Cpk 1.82 |
| 有水平展開 | 找到 D 機的潛在問題 |
| 更新 PFMEA 與管制計畫 | 讓經驗進入品質系統 |
