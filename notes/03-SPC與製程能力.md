# 03 SPC 與製程能力

> 階段 3｜目標：會選管制圖、會算管制界限、會判異常，並能**手算** Ca、Cp、Cpk，解釋結果代表什麼。

---

## 1. SPC 是什麼

### 是什麼

SPC（Statistical Process Control，統計製程管制）是用統計方法**監控製程**，在不良品產生之前發現異常，及早處理。

### 兩種變異

| | 共同原因（機遇原因） | 特殊原因（非機遇原因） |
|---|---|---|
| 英文 | Common cause | Special / Assignable cause |
| 特性 | 製程本來就有、小而隨機 | 偶發、可以找出來 |
| 例子 | 原料的微小差異、環境的微小波動 | 刀具斷裂、換料、參數被調錯 |
| 處理方式 | 要**改善系統**（管理層的責任） | 要**找出並排除**（現場可處理） |
| 管制圖上 | 點在管制界限內隨機分布 | 出現超界或特殊排列 |

> 只剩下共同原因的製程，稱為**統計管制狀態**（In control，製程穩定）。

### 兩個常被混淆的觀念

| | 製程穩定（In control） | 製程有能力（Capable） |
|---|---|---|
| 問的問題 | 製程是否**可預測**？ | 製程是否**符合規格**？ |
| 比較對象 | 管制界限（由製程數據計算） | 規格界限（由客戶決定） |
| 工具 | 管制圖 | Cp、Cpk |

四種組合：

| | 有能力 | 沒能力 |
|---|---|---|
| **穩定** | ✅ 理想狀態，持續監控 | 穩定地做出不良，要**改善系統**（降低變異或調整中心） |
| **不穩定** | 目前合格但不可預測，要先**排除特殊原因** | 最糟的情況，先求穩定，再求能力 |

**順序很重要：先穩定，再談能力。** 製程不穩定時算出來的 Cpk 沒有意義，因為它無法預測未來。

## 2. 管制圖的種類與選用

### 選用流程

```
數據是什麼類型？
│
├─ 計量值（可以量測：尺寸、重量、溫度）
│   │
│   ├─ 每組 n = 1 ─────────────▶ I-MR 圖（個別值－移動全距）
│   ├─ 每組 2 ≤ n ≤ 9 ─────────▶ X̄-R 圖（平均值－全距）  ← 最常用
│   └─ 每組 n ≥ 10 ────────────▶ X̄-S 圖（平均值－標準差）
│
└─ 計數值（只能數：良/不良、缺點個數）
    │
    ├─ 計「不良品」（一個產品只有良或不良）
    │   ├─ 樣本數不固定 ────────▶ p 圖（不良率）
    │   └─ 樣本數固定 ──────────▶ np 圖（不良數）
    │
    └─ 計「缺點數」（一個產品可以有多個缺點）
        ├─ 檢驗單位固定 ────────▶ c 圖（缺點數）
        └─ 檢驗單位不固定 ──────▶ u 圖（單位缺點數）
```

### 對照表

| 管制圖 | 數據 | 例子 |
|---|---|---|
| X̄-R | 計量，每組 2～9 個 | 每小時抽 5 個軸，量外徑 |
| X̄-S | 計量，每組 ≥ 10 個 | 每批抽 20 瓶，量重量 |
| I-MR | 計量，每次 1 個 | 每批化學品的濃度、每天的爐溫 |
| p | 不良率，n 可變 | 每天檢驗數量不同，記錄不良率 |
| np | 不良數，n 固定 | 每批固定抽 100 個，記錄不良數 |
| c | 缺點數，單位固定 | 每片面板的刮傷點數 |
| u | 單位缺點數，單位可變 | 每捲布長度不同，計算每米瑕疵數 |

> **不良品 vs 缺點**：一支手機有 3 道刮傷，它是 **1 個不良品**，但有 **3 個缺點**。

> 計量值的管制圖比計數值**更靈敏**，能更早發現製程偏移，所以能量測時優先用計量值。

## 3. 管制界限的計算

### 基本原理

管制界限 = 中心線 ± 3σ。若製程穩定且呈常態分布，99.73% 的點會落在界限內；點超出界限的機率只有 0.27%，所以一旦超界，很可能是特殊原因造成的。

### X̄-R 圖公式

| | 中心線 CL | 上管制界限 UCL | 下管制界限 LCL |
|---|---|---|---|
| X̄ 圖 | X̿（各組平均的平均） | X̿ + A₂R̄ | X̿ − A₂R̄ |
| R 圖 | R̄（各組全距的平均） | D₄R̄ | D₃R̄ |

### 管制圖係數表

| n | A₂ | D₃ | D₄ | d₂ |
|---|---|---|---|---|
| 2 | 1.880 | 0 | 3.267 | 1.128 |
| 3 | 1.023 | 0 | 2.574 | 1.693 |
| 4 | 0.729 | 0 | 2.282 | 2.059 |
| **5** | **0.577** | **0** | **2.114** | **2.326** |
| 6 | 0.483 | 0 | 2.004 | 2.534 |
| 7 | 0.419 | 0.076 | 1.924 | 2.704 |
| 8 | 0.373 | 0.136 | 1.864 | 2.847 |
| 9 | 0.337 | 0.184 | 1.816 | 2.970 |
| 10 | 0.308 | 0.223 | 1.777 | 3.078 |

> n = 5 最常用，這一列建議背起來。d₂ 用來從全距估計標準差：**σ = R̄ / d₂**。

### 其他管制圖公式

| 管制圖 | 中心線 | 管制界限 |
|---|---|---|
| I 圖 | X̄ | X̄ ± 2.66 MR̄ |
| MR 圖 | MR̄ | UCL = 3.267 MR̄，LCL = 0 |
| p 圖 | p̄ | p̄ ± 3√[p̄(1−p̄)/n] |
| np 圖 | np̄ | np̄ ± 3√[np̄(1−p̄)] |
| c 圖 | c̄ | c̄ ± 3√c̄ |
| u 圖 | ū | ū ± 3√(ū/n) |

（LCL 算出來小於 0 時，取 0）

### 建立管制圖的兩個階段

| 階段 | 目的 | 做法 |
|---|---|---|
| **第一階段**（建立） | 算出可靠的管制界限 | 收集至少 **25 組**（約 100 個數據）→ 計算界限 → 有超界點就查原因，排除後重新計算 |
| **第二階段**（監控） | 用固定的界限監控製程 | 新數據畫在既有界限上，出現異常就處理 |

> 管制界限**不是每次都重算**。只有在製程經過確認的改善或變更後，才重新計算。

## 4. 判異規則

點在界限內，不代表一定正常。以下的**排列**在製程穩定時很少發生，也要視為異常。

### 常用 8 條規則（Nelson Rules）

把 ±3σ 的範圍分成 6 個區域：

```
UCL ─────────────────  +3σ
       A 區
     ─ ─ ─ ─ ─ ─ ─ ─   +2σ
       B 區
     ─ ─ ─ ─ ─ ─ ─ ─   +1σ
       C 區
CL  ═════════════════
       C 區
     ─ ─ ─ ─ ─ ─ ─ ─   −1σ
       B 區
     ─ ─ ─ ─ ─ ─ ─ ─   −2σ
       A 區
LCL ─────────────────  −3σ
```

| 規則 | 內容 | 可能原因 |
|---|---|---|
| 1 | **1 點超出 3σ**（管制界限外） | 突發異常：刀具斷裂、參數錯誤 |
| 2 | **連續 9 點**在中心線同一側 | 製程中心偏移：換料、設定改變 |
| 3 | **連續 6 點**持續上升或下降 | 趨勢：刀具磨損、溫度漂移 |
| 4 | 連續 14 點上下交替 | 兩種來源交替：兩台機台輪流 |
| 5 | 連續 3 點中有 2 點落在同一側 A 區或以外 | 中心偏移的早期訊號 |
| 6 | 連續 5 點中有 4 點落在同一側 B 區或以外 | 中心偏移的早期訊號 |
| 7 | 連續 15 點落在 C 區內（太集中） | 管制界限算錯、數據造假，或混合了不同來源 |
| 8 | 連續 8 點落在 C 區以外（兩側皆有） | 兩種來源混合 |

> **規則 1、2、3 最重要，面試時至少要講得出這三條。** 不同標準的點數略有不同，例如 AIAG 的 SPC 手冊用「連續 7 點同一側」、「連續 7 點上升或下降」；實務上依公司或客戶的規定。

> 規則 7 常被誤會為「很好」：點太集中在中心線附近，其實是**異常**，最常見的原因是管制界限算錯，或數據被修改過。

### 發現異常怎麼處理

1. **停**：依規定暫停生產或加嚴檢驗
2. **查**：依 4M1E 找出特殊原因（看當時有沒有換料、換人、調機）
3. **處置**：排除原因，隔離並評估可疑品
4. **記錄**：在管制圖上註記異常原因與對策
5. **預防**：修訂 SOP 或管制計畫，避免再發生

## 5. 製程能力指標

### 符號

| 符號 | 意義 |
|---|---|
| USL / LSL | 規格上限／規格下限 |
| M | 規格中心 = (USL + LSL) / 2 |
| T | 規格寬度 = USL − LSL |
| μ | 製程平均 |
| σ | 製程標準差 |

### 三個指標

| 指標 | 公式 | 衡量什麼 |
|---|---|---|
| **Ca**（準確度） | (μ − M) / (T/2) | 製程中心**偏離**規格中心多少 |
| **Cp**（精密度） | T / 6σ | 製程**變異**相對規格寬度多小（不管中心有沒有偏） |
| **Cpk**（綜合能力） | min[(USL − μ)/3σ, (μ − LSL)/3σ] | 同時考慮中心與變異，看**離較近的那一側規格** |

關係式：**Cpk = Cp × (1 − |Ca|)**

> Ca 是台灣、日本常用的指標，歐美較少用；Cp 和 Cpk 則是國際通用。

### 比喻：射箭

| | 圖像 | 指標 |
|---|---|---|
| 準（Ca 好） | 箭的平均位置在靶心 | 中心有沒有偏 |
| 精（Cp 好） | 箭都集中在一起 | 變異大不大 |
| 準又精（Cpk 好） | 箭集中在靶心 | 綜合表現 |

只有 Cp 好，可能是「全部集中射在靶的邊緣」；Cpk 才能反映真實的能力。

### 判定標準

| Cpk | 等級 | 處置 | 約略不良率（ppm） |
|---|---|---|---|
| ≥ 1.67 | A+ | 能力充足，可考慮簡化管制 | < 0.6 |
| 1.33 ～ 1.67 | A | 能力足夠，維持現狀 | < 63 |
| 1.00 ～ 1.33 | B | 能力尚可，要加強管制並改善 | < 2,700 |
| 0.67 ～ 1.00 | C | 能力不足，必須改善，加嚴檢驗 | < 45,500 |
| < 0.67 | D | 能力嚴重不足，應全檢並停線檢討 | > 45,500 |

> 不良率是假設常態分布、製程中心對準規格中心時，兩側合計的理論值。

> **常見門檻**：一般量產要求 Cpk ≥ 1.33；車用的新製程或關鍵特性要求 Cpk ≥ 1.67。

Ca 的判定（台灣常用）：

| \|Ca\| | 等級 |
|---|---|
| ≤ 12.5% | A |
| 12.5% ～ 25% | B |
| 25% ～ 50% | C |
| > 50% | D |

### Cp/Cpk 與 Pp/Ppk 的差異

| | Cp / Cpk | Pp / Ppk |
|---|---|---|
| 名稱 | 製程能力（短期） | 製程績效（長期） |
| σ 的算法 | **組內**標準差：σ = R̄ / d₂ | **整體**標準差：所有數據的樣本標準差 s |
| 反映 | 製程**潛在**能做到多好 | 製程**實際**表現 |
| 使用時機 | 製程穩定後的量產監控 | 新製程初期、PPAP 送樣（車用常用 Ppk ≥ 1.67） |

- 製程穩定時，Cpk ≈ Ppk
- **Ppk 明顯小於 Cpk**：代表組與組之間的變異很大，製程不穩定（例如有偏移或漂移），要先找特殊原因

### 前提條件

計算 Cp/Cpk 之前要確認：

1. **製程穩定**：管制圖沒有異常
2. **數據接近常態分布**：先畫直方圖或做常態性檢定；不是常態分布時，要用轉換或非常態的方法
3. **數據量足夠**：一般建議至少 25 組或 100 個數據
4. **量測系統可靠**：GR&R 合格（見 [04-MSA](04-MSA.md)），否則量到的變異有一部分來自量具

## 6. 手算範例

> 某軸的外徑規格為 **10.00 ± 0.15 mm**。每小時抽 5 個，共收集 25 組，算得 X̿ = 10.03 mm，R̄ = 0.10 mm。管制圖確認製程穩定。

### 步驟 1：管制界限（n = 5，A₂ = 0.577，D₃ = 0，D₄ = 2.114）

| | CL | UCL | LCL |
|---|---|---|---|
| X̄ 圖 | 10.030 | 10.03 + 0.577 × 0.10 = **10.088** | 10.03 − 0.577 × 0.10 = **9.972** |
| R 圖 | 0.100 | 2.114 × 0.10 = **0.211** | 0 × 0.10 = **0** |

### 步驟 2：估計標準差（d₂ = 2.326）

σ = R̄ / d₂ = 0.10 / 2.326 = **0.0430**

### 步驟 3：製程能力

- USL = 10.15，LSL = 9.85，M = 10.00，T = 0.30
- **Ca** = (10.03 − 10.00) / (0.30 / 2) = 0.03 / 0.15 = **20%**（B 級）
- **Cp** = 0.30 / (6 × 0.0430) = 0.30 / 0.258 = **1.16**
- **Cpk**：
  - 上側：(10.15 − 10.03) / (3 × 0.0430) = 0.12 / 0.129 = 0.93
  - 下側：(10.03 − 9.85) / (3 × 0.0430) = 0.18 / 0.129 = 1.40
  - 取較小者：**Cpk = 0.93**（C 級，能力不足）
- 驗算：Cp × (1 − |Ca|) = 1.16 × 0.8 = 0.93 ✓

### 步驟 4：解讀與對策

| 觀察 | 解讀 |
|---|---|
| Cp = 1.16，尚可 | 變異本身還可以接受 |
| Cpk = 0.93，偏低 | 主要問題是**中心偏高**（Ca = 20%） |
| 上側比下側差 | 超規的風險在規格上限那一側 |

**對策**：先把製程中心從 10.03 **調回 10.00**。調整中心通常只要改設定（例如刀具補償），比降低變異（換設備、改製程）便宜很多。調回中心後，Cpk 會提升到接近 Cp = 1.16；若要達到 1.33，還需要再降低變異。

> **面試重點**：Cp 和 Cpk 差很多時，代表中心偏移，優先調整中心；Cp 本身就很低時，代表變異太大，要從 4M1E 找出降低變異的方法。

## 7. 補充：σ 水準與六標準差

| Cpk | σ 水準（規格到中心的距離） | 長期不良率（考慮 1.5σ 偏移） |
|---|---|---|
| 1.00 | 3σ | 66,807 ppm |
| 1.33 | 4σ | 6,210 ppm |
| 1.67 | 5σ | 233 ppm |
| 2.00 | 6σ | **3.4 ppm** |

> 六標準差的「每百萬次機會 3.4 次缺點」，是假設製程長期會偏移 1.5σ 後的結果。如果沒有偏移，6σ 的不良率只有約 0.002 ppm。這個差別面試偶爾會問。

## 面試怎麼問 & 參考回答

**Q1：Cp 和 Cpk 有什麼不同？**

> Cp 只看製程變異相對於規格寬度的大小，不考慮中心有沒有偏；Cpk 同時考慮中心位置和變異，取離製程中心較近的那一側規格來計算，所以 Cpk 一定小於或等於 Cp。兩者相等時，代表製程中心剛好在規格中心。一般量產要求 Cpk ≥ 1.33，車用關鍵特性要求 1.67。

**Q2：管制界限和規格界限有什麼不同？**

> 規格界限是客戶或設計訂的，代表產品「應該」在什麼範圍；管制界限是用製程數據算出來的，通常是平均值 ± 3σ，代表製程「實際上」的自然變異範圍。管制界限用來判斷製程是否穩定，規格界限用來判斷產品是否合格。兩者不能混用，例如不能把規格界限畫在管制圖上當管制界限用。

**Q3：管制圖上所有點都在界限內，就代表製程正常嗎？**

> 不一定。除了超出界限，還要看點的排列，例如連續 9 點在中心線同一側代表中心偏移，連續 6 點持續上升或下降代表有趨勢，像是刀具磨損。還有一種是連續 15 點都集中在中心線附近，看起來很好，其實可能是管制界限算錯或數據有問題。

**Q4：Cpk 很低，你會怎麼改善？**

> 先比較 Cp 和 Cpk。如果 Cp 還不錯但 Cpk 低，代表中心偏移，優先調整製程中心，通常改設定就能改善；如果 Cp 本身就低，代表變異太大，要用 4M1E 找出變異來源，例如設備精度、原料差異、作業方法不一致。另外也要先確認製程是否穩定，以及量測系統是否合格，避免因為量具的變異而低估了製程能力。

**Q5：Cpk 和 Ppk 有什麼不同？**

> 差別在標準差的算法。Cpk 用組內變異（R̄/d₂），反映製程的短期潛在能力；Ppk 用所有數據的整體標準差，包含組與組之間的變異，反映長期實際表現。製程穩定時兩者會很接近；如果 Ppk 明顯小於 Cpk，代表組間變異大，製程不穩定。車用產業在 PPAP 階段通常要求 Ppk ≥ 1.67。

**Q6：計數值和計量值的管制圖要怎麼選？**

> 能量測的特性（尺寸、重量）用計量值管制圖，最常用 X̄-R 圖；只能判定良或不良時，看不良率用 p 圖、不良數用 np 圖；計算缺點數用 c 圖或 u 圖。計量值的管制圖比較靈敏，所以能量測時優先用計量值。
