# 01 品質基礎

> 階段 1｜目標：能用自己的話說清楚「品質是什麼」、「品保單位怎麼分工」、「問題從哪裡來」。

---

## 1. 品質是什麼

### 是什麼

| 來源 | 定義 | 重點 |
|---|---|---|
| Juran（朱蘭） | 適用性（Fitness for use） | 站在**使用者**角度 |
| Crosby（克勞斯比） | 符合要求（Conformance to requirements） | 站在**規格**角度，「零缺點」 |
| ISO 9000:2015 | 一組固有特性滿足要求的程度 | 國際標準的正式定義 |

一句話版本：**品質就是穩定地做出符合客戶要求的產品。**「穩定」這個詞很重要，偶爾做出一個好產品不算有品質，每一個都好才算。

### 品質管理的演進

```
檢驗（挑出壞的） → 品質管制 QC（用統計控制製程） → 品質保證 QA（用系統預防問題） → 全面品質管理 TQM（全員參與、持續改善）
```

演進方向是從**事後挑**到**事前防**。面試時講得出這個趨勢，就代表觀念正確。

---

## 2. QC 與 QA 的差異

| | QC 品質管制 | QA 品質保證 |
|---|---|---|
| 導向 | 產品導向 | 流程／系統導向 |
| 時機 | 事後檢查 | 事前預防 |
| 目的 | 找出不良品 | 讓不良品不發生 |
| 例子 | 進料檢驗、出貨抽檢 | 制定 SOP、稽核、FMEA、供應商管理 |

比喻：QC 是「抓到考卷寫錯的地方」，QA 是「設計讀書方法，讓學生不容易寫錯」。

## 3. 品保單位的分工

依產品流程，從進料到出貨：

```
供應商 ──▶ IQC ──▶ 生產線（IPQC） ──▶ FQC ──▶ 倉庫 ──▶ OQC ──▶ 客戶
            ▲                                                   │
           SQE                    QE（製程品質）               CQE（客訴）
```

| 職稱 | 全名 | 主要工作 |
|---|---|---|
| IQC | Incoming QC 進料檢驗 | 依抽樣計畫檢驗原物料、零件是否符合規格 |
| IPQC | In-Process QC 製程檢驗 | 首件檢驗、巡檢、監控製程參數 |
| FQC | Final QC 成品檢驗 | 產品完成後的全檢或抽檢 |
| OQC | Outgoing QC 出貨檢驗 | 出貨前的最後把關（包裝、標籤、外觀、功能） |
| QE | Quality Engineer 品質工程師 | 分析製程異常、SPC 監控、改善專案、推動品質手法 |
| SQE | Supplier QE 供應商品質工程師 | 供應商稽核、輔導、進料異常處理 |
| CQE | Customer QE 客戶品質工程師 | 處理客訴、撰寫 8D、對應客戶稽核 |
| DQA | Design QA 設計品保 | 新產品開發階段的驗證與測試 |

> 面試時，要先知道你應徵的是哪一個職位。職缺寫「品質工程師」，實際工作可能偏 QE、SQE 或 CQE，看 JD 的工作內容來判斷。

## 4. PDCA 循環

### 是什麼

戴明循環，持續改善最基本的架構：

| 步驟 | 內容 | 例子（降低焊接不良） |
|---|---|---|
| **P**lan 計畫 | 找問題、分析原因、訂目標與對策 | 不良率 3%，目標降到 1%；分析發現溫度不穩 |
| **D**o 執行 | 依計畫執行對策 | 更換溫控器，試行兩週 |
| **C**heck 檢查 | 確認效果是否達成 | 不良率降到 0.8% |
| **A**ct 處置 | 有效就標準化；無效就回到 P | 修訂 SOP，水平展開到其他產線 |

### 重點

- 8D、DMAIC 等問題解決方法，本質上都是 PDCA 的延伸
- **A 最常被忽略**：改善有效之後，一定要**標準化**（改 SOP、改管制計畫），否則問題會再發生

## 5. 4M1E：問題從哪裡來

### 是什麼

分析製程變異來源的架構，也是魚骨圖最常用的分類方式。

| 因素 | 英文 | 檢查重點 |
|---|---|---|
| 人 | Man | 是否經過訓練、有沒有照 SOP 做、是否換了人 |
| 機 | Machine | 設備保養、參數、治具磨損 |
| 料 | Material | 供應商、批號、規格是否變更 |
| 法 | Method | SOP 是否正確、作業方法是否變更 |
| 環 | Environment | 溫度、濕度、粉塵、靜電 |

有時會再加上 **Measurement（量測）**，合稱 **5M1E**：量具是否校正、量測方法是否一致（之後在 MSA 會深入學）。

### 何時用

- 製程發生異常時，用來**有系統地**列出可能原因，避免漏掉
- 製程有變更時（4M 變更管理），例如換供應商或換機台，要通知品保單位並做驗證

## 6. 品質成本（COQ）

### 是什麼

| 類別 | 說明 | 例子 |
|---|---|---|
| 預防成本 | 防止不良發生 | 教育訓練、FMEA、製程設計、供應商輔導 |
| 鑑定成本 | 檢查是否不良 | 檢驗人力、量測設備、校正、測試 |
| 內部失敗成本 | 出貨**前**發現的不良 | 報廢、重工、停線 |
| 外部失敗成本 | 出貨**後**才發現的不良 | 客訴、退貨、召回、商譽損失 |

### 重點：1-10-100 法則

同一個問題，在設計階段解決要花 1 元，到生產階段要花 10 元，到客戶端則要花 100 元。

**結論**：投資在**預防成本**最划算。這也是為什麼品質管理要從檢驗走向預防。

## 7. 常見術語

| 術語 | 說明 |
|---|---|
| 規格（Spec）/ 公差 | 例如 10.0 ± 0.1 mm，USL = 10.1、LSL = 9.9 |
| 良率（Yield） | 良品數 ÷ 總數 |
| FPY 直通率 | 第一次就做對、不需重工的比率 |
| DPPM | 每百萬個產品中的不良數（Defect Parts Per Million） |
| 首件檢驗（FAI） | 開線、換線、換料後，確認第一個產品合格才量產 |
| 不合格品處理 | 標示 → 隔離 → 評審（MRB）→ 處置（報廢、重工、特採、退貨） |
| 特採（Deviation / Waiver） | 產品不符合規格，但經評估不影響使用，經客戶或相關單位同意後允收 |
| MRB | 物料審查委員會，由品保、生產、工程等單位共同決定不合格品如何處置 |
| 可追溯性 | 透過批號、序號，追查到原料、機台、作業員、時間 |

## 面試怎麼問 & 參考回答

**Q1：QC 和 QA 有什麼不同？**

> QC 偏產品導向，是在產品做出來之後透過檢驗找出不良，例如 IQC、OQC；QA 偏系統導向，是透過制度和流程預防不良發生，例如制定 SOP、做 FMEA、稽核。QC 是 QA 的一部分，現在的品質管理趨勢是從事後檢驗走向事前預防。

**Q2：IQC、IPQC、OQC 各負責什麼？**

> 依產品流程區分：IQC 在進料端檢驗原物料；IPQC 在製程中做首件檢驗和巡檢，即時發現製程異常；OQC 在出貨前做最後確認，避免不良品流到客戶端。越早發現問題，成本越低。

**Q3：什麼是品質成本？你認為哪一種最該投資？**

> 品質成本分為預防、鑑定、內部失敗和外部失敗四類。最該投資的是預防成本，因為根據 1-10-100 法則，問題越晚發現，處理成本越高，外部失敗還會傷害商譽。

**Q4：產線不良率突然升高，你會怎麼開始分析？**

> 先確認問題的範圍（哪條線、哪個時段、哪種不良），同時做圍堵（隔離可疑品）。接著用 4M1E 檢查近期有沒有變更：是否換了作業員、設備參數有沒有調整、原料是否換批或換供應商、SOP 是否修改、環境溫濕度有沒有變化。找到差異點後，再驗證是不是根本原因。

**Q5：什麼是特採？**

> 產品不符合規格，但經過評估確認不影響功能和安全，在客戶或 MRB 同意下有條件允收。特採必須有正式的申請和核准紀錄，並追蹤原因、避免再發生，不能變成常態。
