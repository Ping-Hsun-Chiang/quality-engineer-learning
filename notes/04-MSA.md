# 04 MSA 量測系統分析

> 階段 3｜目標：知道為什麼要先做 MSA，會解讀 GR&R 結果（%GRR、ndc），並能從 EV 和 AV 判斷問題出在量具還是人。

---

## 1. 為什麼需要 MSA

### 是什麼

MSA（Measurement System Analysis，量測系統分析）用來評估**量測系統本身的變異**有多大。量測系統不只是量具，而是包含：

> 量具 + 量測人員 + 量測方法 + 環境 + 被量測的零件

### 核心觀念

我們看到的變異，其實是兩種變異的總和：

```
觀測到的變異  =  製程（零件）的真實變異  +  量測系統的變異
   σ²總         =        σ²製程            +       σ²量測
```

如果量測系統的變異太大，會發生：

| 問題 | 後果 |
|---|---|
| 把良品判成不良 | 誤判報廢，浪費成本（**誤判，型一錯誤**） |
| 把不良品判成良品 | 不良品流到客戶端（**漏判，型二錯誤**） |
| Cpk 被低估 | 製程其實沒問題，卻花錢改善製程 |
| 管制圖誤報 | 看到的「異常」其實是量測造成的 |

> **一句話**：數據不可信，後面的 SPC、Cpk、改善全部都沒有意義。所以 MSA 要**在 SPC 之前**做。

### 什麼時候要做 MSA

- 新量具導入、新製程量產前（車用 PPAP 必須提交）
- 量具維修、重新校正、移動位置後
- 量測人員或量測方法變更
- 定期執行（例如每年一次）
- 製程或客戶對量測結果有疑慮時

---

## 2. MSA 與校正的差異

| | 校正（Calibration） | MSA |
|---|---|---|
| 對象 | **量具**本身 | **整個量測系統**（量具 + 人 + 方法 + 環境） |
| 問的問題 | 量具準不準？ | 這套量測系統能不能用來管制這個製程？ |
| 做法 | 用標準件比對，追溯到國家標準 | 多人、多零件、多次重複量測，做統計分析 |

> 量具校正合格，**不代表** MSA 會合格。例如量具很準，但不同人的量法不一樣，GR&R 還是會很差。

---

## 3. 量測系統的五種特性

分成**位置**（準不準）和**寬度**（精不精）兩大類：

| 類別 | 特性 | 意義 | 評估方式 |
|---|---|---|---|
| 位置 | **偏倚**（Bias） | 量測平均值與真值的差 | 同一標準件量 10 次以上，比較平均與標準值 |
| 位置 | **線性**（Linearity） | 在量程內的不同位置，偏倚是否一致 | 取量程內 5 個以上的標準件，各自算偏倚，看偏倚是否隨尺寸改變 |
| 位置 | **穩定性**（Stability） | 隨著時間，偏倚是否改變 | 定期量同一標準件，畫管制圖 |
| 寬度 | **重複性**（Repeatability） | **同一人**、同一量具，重複量同一零件的變異 | GR&R 中的 **EV** |
| 寬度 | **再現性**（Reproducibility） | **不同人**量同一零件，平均值之間的差異 | GR&R 中的 **AV** |

```
       偏倚                    重複性                   再現性
                                                     甲    乙
   真值  量測平均             ▁▃▇▃▁                  ▁▃▇▃▁ ▁▃▇▃▁
    │      │                同一人量很多次             │     │
    ▼      ▼                的分布寬度                甲乙平均的差
    ├──────┤
    差距 = 偏倚
```

### 解析度（Resolution）

量具能顯示的最小刻度。**10 分之 1 原則**：量具的解析度應小於等於**公差**（或製程變異）的 1/10。

> 例：公差 ±0.05 mm（總寬 0.10 mm），量具解析度至少要 0.01 mm，所以要用分厘卡，不能用解析度 0.02 mm 的游標卡尺。

## 4. GR&R（量具重複性與再現性）

### 是什麼

GR&R（Gage Repeatability & Reproducibility）是 MSA 中最常做、面試最常問的分析，用來評估量測系統的**寬度**變異。

```
            總變異 TV
          ┌────┴────┐
       量測 GRR    零件 PV
     ┌────┴────┐
  重複性 EV  再現性 AV
   （量具）    （人）
```

| 縮寫 | 全名 | 白話 |
|---|---|---|
| EV | Equipment Variation（重複性） | 同一人重複量的變異，**通常來自量具** |
| AV | Appraiser Variation（再現性） | 不同人之間的變異，**通常來自人或方法** |
| GRR | 量測系統的總變異 | √(EV² + AV²) |
| PV | Part Variation | 零件之間的真實變異 |
| TV | Total Variation | √(GRR² + PV²) |

### 標準做法（AIAG MSA 手冊）

| 項目 | 一般設定 |
|---|---|
| 零件數 n | **10 個**，要涵蓋製程的實際變異範圍（不能都挑差不多的） |
| 量測人員 k | **2～3 人**，平常就在做這項量測的人 |
| 重複次數 r | **2～3 次** |
| 總量測次數 | 3 × 10 × 3 = 90 次 |

執行重點：

1. 零件編號，但**量測人員看不到編號**（盲測），避免記住上次的結果
2. **隨機順序**量測
3. 量測人員依照**平常的 SOP** 量測
4. 讀值要讀到量具的解析度，不要自行捨入

### 平均值與全距法（Average & Range Method）

| 步驟 | 公式 | 說明 |
|---|---|---|
| 1. 重複性 | EV = R̿ × K₁ | R̿：每人每個零件 r 次量測的全距，取全部平均 |
| 2. 再現性 | AV = √[(X̄diff × K₂)² − EV²/(n·r)] | X̄diff：各量測人員平均值的最大差；根號內為負時取 0 |
| 3. 量測系統 | GRR = √(EV² + AV²) | |
| 4. 零件變異 | PV = Rp × K₃ | Rp：各零件平均值的全距 |
| 5. 總變異 | TV = √(GRR² + PV²) | |
| 6. 百分比 | %EV = EV/TV，%AV = AV/TV，%GRR = GRR/TV，%PV = PV/TV | 都乘以 100% |
| 7. 鑑別組數 | ndc = 1.41 × (PV / GRR) | 無條件捨去取整數 |

**係數表**（AIAG MSA 第四版）：

| 重複次數 r | K₁ | | 量測人數 k | K₂ | | 零件數 n | K₃ |
|---|---|---|---|---|---|---|---|
| 2 | 0.8862 | | 2 | 0.7071 | | 5 | 0.4030 |
| 3 | 0.5908 | | 3 | 0.5231 | | 8 | 0.3375 |
| | | | | | | **10** | **0.3146** |

（完整 K₃ 表：n = 2～10 依序為 0.7071、0.5231、0.4467、0.4030、0.3742、0.3534、0.3375、0.3249、0.3146）

> **陷阱**：%EV + %AV **不等於** %GRR，因為變異是**平方相加**，不是直接相加。

### 另一種分母：%公差（%Tolerance）

| 指標 | 公式 | 用途 |
|---|---|---|
| %GRR（對總變異） | GRR / TV | 量測系統能不能用來**管制製程**（SPC） |
| %GRR（對公差） | 6 × GRR / (USL − LSL) | 量測系統能不能用來**判定產品合格與否**（檢驗） |

> 製程很穩定、零件差異很小時，%GRR（對總變異）會偏高，但 %公差可能沒問題。報告時兩者都要列出，並說明用途。

---

## 5. 判定標準

### %GRR

| %GRR | 判定 | 處置 |
|---|---|---|
| **< 10%** | ✅ 可接受 | 量測系統良好 |
| **10% ～ 30%** | ⚠️ 有條件接受 | 依特性重要性、量具成本、維修成本決定；需經客戶同意 |
| **> 30%** | ❌ 不可接受 | 必須改善量測系統 |

### ndc（鑑別組數）

| ndc | 意義 |
|---|---|
| **≥ 5** | ✅ 可接受，量測系統能把製程變異分成 5 組以上 |
| < 5 | ❌ 量測系統解析能力不足，分不出零件之間的差異 |

> ndc = 1 代表量測系統完全分辨不出零件之間的差異，量到的都是「雜訊」。

---

## 6. 結果分析：問題出在哪？

| 現象 | 判斷 | 改善方向 |
|---|---|---|
| **EV > AV** | 問題在**量具** | 保養、維修或更換量具；改善夾治具，讓零件定位一致；提高解析度 |
| **AV > EV** | 問題在**人或方法** | 加強教育訓練；統一量測方法（量哪個位置、施力多大）；做目視輔助或防呆 |
| 某一人的 R 特別大 | 這個人的手法不穩定 | 個別訓練，觀察他的量測方式 |
| 某一人的平均特別偏 | 這個人的量法和其他人不同 | 比對量測方法，統一 SOP |
| %PV 很低、ndc 很小 | 零件樣本的變異太小 | 重新挑選能涵蓋製程範圍的零件 |

### GR&R 的管制圖檢查

| 圖 | 怎麼看 | 期望結果 |
|---|---|---|
| R 圖（依量測人員分組） | 點超出 UCL = D₄R̿ | **全部在界限內**：每個人的重複量測一致 |
| X̄ 圖（依量測人員分組） | 管制界限 = X̿ ± A₂R̿ | **一半以上的點超出界限**：量測系統分得出零件之間的差異 |

> X̄ 圖要「超出」才是好的，這點和一般 SPC 相反。因為這裡的管制界限代表**量測雜訊**的範圍，零件之間的差異應該要比雜訊大。

---

## 7. 平均值與全距法 vs ANOVA 法

| | 平均值與全距法 | ANOVA 法（變異數分析） |
|---|---|---|
| 計算 | 簡單，可以手算 | 較複雜，通常用 Minitab 等軟體 |
| 交互作用 | **無法**估計人員與零件的交互作用 | **可以**估計（例如某人量某種零件特別不準） |
| 精確度 | 較低 | 較高，AIAG 建議優先使用 |

## 8. 計數型 MSA

量測結果只有「OK / NG」（例如目視檢查、通止規）時，用計數型 MSA。

### 做法

- 準備約 **50 個**零件，包含良品、不良品，以及**接近臨界**的零件
- 由專家先判定每個零件的「標準答案」
- 3 位檢驗員各判定 2～3 次，盲測、隨機順序

### 判定指標

| 指標 | 意義 | 可接受 | 有條件接受 | 不可接受 |
|---|---|---|---|---|
| 有效性 | 判定正確的比率 | ≥ 90% | 80% ～ 90% | < 80% |
| 漏判率（Miss rate） | 不良品判成良品 | ≤ 2% | 2% ～ 5% | > 5% |
| 誤判率（False alarm） | 良品判成不良品 | ≤ 5% | 5% ～ 10% | > 10% |
| Kappa | 判定的一致性（排除碰巧猜對） | ≥ 0.75 | 0.40 ～ 0.75 | < 0.40 |

> **漏判率的標準最嚴格**，因為漏判會讓不良品流到客戶端。

---

## 9. 手算範例

> 某零件外徑公差為 ±0.30 mm（公差寬度 0.60 mm）。3 位量測人員、10 個零件、每人量 3 次。已算得：
> - R̿（全部全距的平均）= 0.020
> - X̄diff（三人平均值的最大差）= 0.015
> - Rp（零件平均值的全距）= 0.40

| 步驟 | 計算 | 結果 |
|---|---|---|
| EV | 0.020 × 0.5908 | **0.01182** |
| AV | √[(0.015 × 0.5231)² − 0.01182² / (10 × 3)] = √(0.00006157 − 0.00000465) | **0.00754** |
| GRR | √(0.01182² + 0.00754²) | **0.01402** |
| PV | 0.40 × 0.3146 | **0.12584** |
| TV | √(0.01402² + 0.12584²) | **0.12662** |

| 指標 | 計算 | 結果 | 判定 |
|---|---|---|---|
| %EV | 0.01182 / 0.12662 | 9.3% | |
| %AV | 0.00754 / 0.12662 | 6.0% | |
| **%GRR** | 0.01402 / 0.12662 | **11.1%** | ⚠️ 有條件接受 |
| %PV | 0.12584 / 0.12662 | 99.4% | |
| **ndc** | 1.41 × 0.12584 / 0.01402 = 12.66 | **12** | ✅ |
| **%公差** | 6 × 0.01402 / 0.60 | **14.0%** | ⚠️ 有條件接受 |

**解讀**：
- %GRR = 11.1%，略高於 10%，屬於有條件接受
- EV（9.3%）> AV（6.0%），主要問題在**量具的重複性**，應優先檢查量具和夾治具
- ndc = 12 ≥ 5，量測系統分得出零件之間的差異
- 驗證：9.3% + 6.0% = 15.3% ≠ 11.1%，因為是平方相加：√(9.3² + 6.0²) ≈ 11.1 ✓

## 面試怎麼問 & 參考回答

**Q1：為什麼要做 MSA？**

> 因為我們看到的變異，包含了製程本身的變異和量測系統的變異。如果量測系統的變異太大，會造成誤判和漏判，算出來的 Cpk 也會被低估，管制圖會出現假警報。所以在做 SPC 或計算製程能力之前，要先確認量測系統是可信的。

**Q2：GR&R 的判定標準是什麼？**

> %GRR 小於 10% 可接受；10% 到 30% 有條件接受，要看特性的重要性和改善成本，通常需要客戶同意；大於 30% 不可接受，必須改善。另外鑑別組數 ndc 要大於等於 5，代表量測系統能分辨出零件之間的差異。

**Q3：重複性和再現性有什麼不同？GR&R 不合格時怎麼改善？**

> 重複性 EV 是同一個人用同一個量具重複量同一個零件的變異，通常反映量具本身的問題；再現性 AV 是不同人量同一個零件的差異，通常反映人員或方法的問題。如果 EV 比較大，就檢查量具的保養、夾治具和解析度；如果 AV 比較大，就加強人員訓練、統一量測方法，例如規定量測位置和施力方式。

**Q4：量具已經校正合格了，為什麼還要做 MSA？**

> 校正只確認量具本身的準確度，MSA 評估的是整個量測系統，包含人員、方法和環境。量具很準，但如果不同人量的位置或施力不同，再現性還是會很差。所以兩者都需要。

**Q5：%EV = 8%、%AV = 6%，%GRR 是 14% 嗎？**

> 不是。變異是平方相加，所以 %GRR = √(8² + 6²) = 10%。

**Q6：目視檢查這種只有 OK/NG 的量測，要怎麼做 MSA？**

> 用計數型 MSA。準備大約 50 個零件，包含良品、不良品和接近臨界的零件，由專家判定標準答案，再讓 3 位檢驗員各判定 2 到 3 次。評估有效性、漏判率、誤判率和 Kappa 值。其中漏判率的標準最嚴格，通常要小於 2%，因為漏判會讓不良品流到客戶端。
