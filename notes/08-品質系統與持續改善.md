# 08 品質系統與持續改善

> 階段 5｜目標：了解 ISO 9001 與 IATF 16949 的架構、車用五大核心工具（APQP、PPAP、FMEA、MSA、SPC）的關係，以及持續改善（CIP）的常用方法。這一階段以「**講得出架構**」為主，不需要背條文。

## 1. ISO 9001:2015 品質管理系統

### 是什麼

國際標準化組織（ISO）發布的品質管理系統標準，**適用所有產業**，是最基本、最普及的品質系統認證。

### 七大品質管理原則

| 原則 | 一句話 |
|---|---|
| 以顧客為重 | 滿足並超越顧客期望 |
| 領導 | 高階主管建立方向，並投入資源 |
| 全員參與 | 每個人都對品質有責任 |
| 流程導向 | 把活動當成相互關聯的流程來管理 |
| 改善 | 持續改善是永久目標 |
| 以證據為依據的決策 | 用數據做決策，而不是憑感覺 |
| 關係管理 | 管理與供應商等利害關係人的關係 |

### 條文架構與 PDCA

| 條文 | 內容 | PDCA |
|---|---|---|
| 4 組織背景 | 內外部議題、利害關係者、品質系統範圍 | Plan |
| 5 領導 | 品質政策、組織職責 | Plan |
| 6 規劃 | **風險與機會**、品質目標 | Plan |
| 7 支援 | 資源、人員能力、**量測資源（校正）**、文件化資訊 | Plan / Do |
| 8 營運 | 產品要求、設計開發、**採購（供應商管理）**、生產、放行、**不合格品管制** | Do |
| 9 績效評估 | 監視量測、顧客滿意、**內部稽核**、管理審查 | Check |
| 10 改善 | **不符合事項與矯正措施**、持續改善 | Act |

> 第 1～3 條是範圍、引用標準與名詞定義。2015 版的重點變化是**風險基礎思維**（Risk-based thinking），並取消「品質手冊」和「管理代表」的強制要求。

### 稽核的種類

| 類型 | 誰稽核誰 | 例子 |
|---|---|---|
| 第一方稽核 | 公司**稽核自己** | 內部稽核 |
| 第二方稽核 | **客戶**稽核供應商 | 客戶來廠稽核、公司稽核自己的供應商 |
| 第三方稽核 | **獨立驗證機構**稽核 | ISO 9001 認證稽核（例如 SGS、BSI、TÜV） |

稽核發現的等級：

| 等級 | 意義 |
|---|---|
| 主要缺失（Major NC） | 系統性失效，或可能導致不合格品流到客戶，**可能影響證書** |
| 次要缺失（Minor NC） | 單一、偶發的不符合 |
| 觀察事項（OFI） | 尚未違反要求，但有改善空間 |

## 2. IATF 16949:2016 汽車業品質管理系統

### 是什麼

以 ISO 9001 為**基礎**，再加上汽車產業的額外要求。汽車供應鏈（Tier 1、Tier 2）的廠商幾乎都要取得。

### 比 ISO 9001 多了什麼

| 項目 | 說明 |
|---|---|
| 客戶特殊要求（CSR） | 各車廠（如 Ford、GM、Toyota）各自的額外要求，必須遵守 |
| **五大核心工具** | APQP、PPAP、FMEA、MSA、SPC 為必要工具 |
| 產品安全 | 對安全相關的產品與製程有特別管理要求 |
| 製造過程稽核 | 除了系統稽核，還要做**製程稽核**與**產品稽核** |
| 保固管理 | 包含**NTF**（No Trouble Found，客戶退回但查無異常）的分析 |
| 防錯 | 要求使用防呆，並定期驗證防呆有效 |
| 供應商管理 | 要求供應商至少取得 ISO 9001，並逐步朝 IATF 16949 發展 |
| 緊急應變計畫 | 停電、天災、關鍵設備故障時，如何持續供貨 |

### 其他產業的品質系統

| 標準 | 產業 |
|---|---|
| ISO 13485 | 醫療器材 |
| AS9100 | 航太 |
| TL 9000 | 電信 |
| ISO/IEC 17025 | 測試與校正實驗室 |
| IECQ QC 080000 | 電子業有害物質管理（對應 RoHS、REACH） |
| ISO 14001、ISO 45001 | 環境管理、職業安全衛生（常與 ISO 9001 整合） |

## 3. 車用五大核心工具

### 五大工具的關係

```
APQP（產品開發的整體流程）
 │
 ├─ 設計階段 ──── DFMEA
 ├─ 製程設計 ──── PFMEA ──▶ 管制計畫
 ├─ 製程確認 ──── MSA（量測可信嗎？）──▶ SPC（製程穩定、有能力嗎？）
 │
 └─ 送樣核准 ──── PPAP（把以上證據交給客戶核准）
```

| 工具 | 一句話 | 筆記 |
|---|---|---|
| **APQP** | 新產品從規劃到量產的**開發流程** | 本篇 |
| **FMEA** | 事前找出風險 | [07-FMEA](07-FMEA.md) |
| **MSA** | 確認量測系統可信 | [04-MSA](04-MSA.md) |
| **SPC** | 監控製程穩定與能力 | [03-SPC與製程能力](03-SPC與製程能力.md) |
| **PPAP** | 量產前送客戶**核准** | 本篇 |

### APQP 產品品質先期規劃

把新產品開發分成五個階段，每個階段有明確的產出，階段之間要經過審查才能進入下一階段：

| 階段 | 名稱 | 主要產出 |
|---|---|---|
| 1 | 計畫與定義 | 客戶需求、設計目標、品質目標、初始材料清單 |
| 2 | 產品設計與開發 | **DFMEA**、圖面、特殊特性清單、原型管制計畫 |
| 3 | 製程設計與開發 | 製程流程圖、**PFMEA**、試產管制計畫、包裝規格 |
| 4 | 產品與製程確認 | 試量產、**MSA**、**初期製程能力（Ppk）**、**PPAP** |
| 5 | 回饋、評估與矯正 | 量產後持續改善、降低變異、客戶滿意 |

管制計畫分三種：**原型**（Prototype）→ **試產**（Pre-launch）→ **量產**（Production），隨開發階段逐步更新。

### PPAP 生產件核准程序

供應商在量產前，向客戶提交證據，證明「**用量產的製程，能穩定做出符合要求的產品**」。

**18 項要素**：

| # | 要素 | # | 要素 |
|---|---|---|---|
| 1 | 設計紀錄（圖面） | 10 | 材料／性能測試結果 |
| 2 | 工程變更文件 | 11 | **初始製程研究**（Ppk） |
| 3 | 客戶工程核准 | 12 | 合格實驗室文件 |
| 4 | **DFMEA** | 13 | 外觀核准報告（AAR） |
| 5 | **製程流程圖** | 14 | 生產件樣品 |
| 6 | **PFMEA** | 15 | 標準樣品 |
| 7 | **管制計畫** | 16 | 檢具 |
| 8 | **MSA** | 17 | 客戶特殊要求 |
| 9 | **尺寸量測結果** | 18 | **零件提交保證書（PSW）** |

**提交等級**：

| 等級 | 提交內容 |
|---|---|
| 1 | 只提交 PSW |
| 2 | PSW + 樣品 + 部分資料 |
| **3** | PSW + 樣品 + **全部資料**（**未指定時的預設等級**） |
| 4 | PSW + 客戶指定的資料 |
| 5 | PSW + 樣品 + 全部資料，並在**供應商現場**審查 |

**什麼時候要重新提交 PPAP**：新零件、設計變更、**換材料或供應商**、**換製程或機台**、換工廠、模具重大修改、停產 12 個月以上再生產等。

> 回想 [8D 案例](../cases/8D-外殼卡扣毛邊客訴.md)：X100 從 A 機擴充到 B 機生產，在車用產業屬於製程變更，**需要通知客戶，甚至重新提交 PPAP**。沒有做變更管理，就是那次客訴的系統原因之一。

## 4. 持續改善（CIP）

### 是什麼

CIP（Continuous Improvement Process）是**持續、漸進地改善**產品、流程與服務的觀念與做法。ISO 9001 第 10 條、IATF 16949 都明確要求持續改善。

### 改善的兩種方式

| | 持續改善（Kaizen） | 突破改善（Kaikaku） |
|---|---|---|
| 幅度 | 小步、漸進 | 大幅、一次到位 |
| 參與者 | 全員，特別是現場人員 | 專案團隊、管理層 |
| 投資 | 低 | 高 |
| 例子 | 提案改善、5S、QCC | 新設備、新製程、自動化 |

### 常用的改善方法

#### 5S

| S | 日文 | 中文 | 做法 |
|---|---|---|---|
| 1 | Seiri | **整理** | 區分要與不要，不要的清除 |
| 2 | Seiton | **整頓** | 要的東西定位、定量、標示，30 秒內找到 |
| 3 | Seiso | **清掃** | 清掃並同時點檢設備 |
| 4 | Seiketsu | **清潔** | 把前 3S 標準化、制度化 |
| 5 | Shitsuke | **素養** | 養成遵守規定的習慣 |

#### 精實生產的八大浪費

| 浪費 | 例子 |
|---|---|
| 不良 | 報廢、重工 |
| 過量生產 | 做出還不需要的產品（**最嚴重的浪費**，會隱藏其他問題） |
| 等待 | 等料、等機台、等檢驗結果 |
| 未被利用的人才 | 員工的想法沒有被採納 |
| 運送 | 不必要的搬運 |
| 庫存 | 過多的原料、在製品、成品 |
| 動作 | 彎腰、走動、找東西 |
| 過度加工 | 超過客戶要求的加工或檢驗 |

> 英文口訣 **DOWNTIME**：Defects、Overproduction、Waiting、Non-utilized talent、Transportation、Inventory、Motion、Extra-processing。

#### 防呆（Poka-Yoke）

讓錯誤**不可能發生**或**發生時立即被發現**。

| 類型 | 例子 |
|---|---|
| 接觸式 | 治具形狀讓零件放反就放不進去 |
| 定數式 | 零件盒的螺絲沒拿完，下一步就無法啟動 |
| 動作順序式 | 沒有先掃描條碼，設備不會啟動 |

#### 品管圈（QCC）

由現場同一工作單位的 **3～10 人**組成小組，用 QC 七大手法自主改善工作上的問題。步驟依 PDCA：選定主題 → 現況把握 → 設定目標 → 要因分析 → 對策擬定 → 對策實施 → 效果確認 → 標準化 → 檢討與改進。

### 六標準差（Six Sigma）

用**統計方法降低變異**的改善方法，目標是每百萬次機會只有 **3.4 次缺點**（見 [03-SPC](03-SPC與製程能力.md) 第 7 節）。

**DMAIC**（改善既有流程）：

| 階段 | 做什麼 | 常用工具 |
|---|---|---|
| **D**efine 定義 | 定義問題、範圍、目標、客戶需求 | 專案章程、SIPOC、VOC |
| **M**easure 量測 | 量測現況，確認量測系統可信 | **MSA**、**製程能力**、柏拉圖 |
| **A**nalyze 分析 | 找出並驗證關鍵原因 | 魚骨圖、迴歸、假設檢定 |
| **I**mprove 改善 | 擬定並驗證對策 | **DOE**（實驗設計）、防呆 |
| **C**ontrol 管制 | 維持改善成果 | **SPC**、管制計畫、標準化 |

> 新產品或新流程設計用 **DMADV**（Define、Measure、Analyze、Design、Verify）。

**角色（帶級）**：

| 帶級 | 角色 |
|---|---|
| 盟主（Champion） | 高階主管，選定專案、提供資源 |
| 黑帶大師（MBB） | 培訓與指導黑帶 |
| 黑帶（BB） | 全職領導改善專案 |
| 綠帶（GB） | 兼職參與或領導較小的專案 |
| 黃帶（YB） | 了解基本觀念，參與專案 |

## 5. 品質 KPI

品質工程師常被要求追蹤、報告這些指標：

| 指標 | 計算 | 用途 |
|---|---|---|
| 良率／直通率（FPY） | 一次就良品的數量 ÷ 投入數 | 製程表現 |
| DPPM | 不良數 ÷ 出貨數 × 1,000,000 | 對客戶的品質表現 |
| 客訴件數 | 每月客訴件數 | 客戶滿意 |
| 8D 結案率／時效 | 準時結案的 8D ÷ 全部 8D | 問題處理效率 |
| IQC 批合格率 | 允收批數 ÷ 檢驗批數 | 供應商品質 |
| 不良品成本（COPQ） | 報廢 + 重工 + 客訴處理 + 退貨成本 | 品質成本（見 [01-品質基礎](01-品質基礎.md)） |
| Cpk 達成率 | Cpk ≥ 1.33 的關鍵特性 ÷ 全部關鍵特性 | 製程能力 |

## 面試怎麼問 & 參考回答

**Q1：ISO 9001 和 IATF 16949 有什麼不同？**

> IATF 16949 是以 ISO 9001 為基礎，再加上汽車產業的額外要求，例如必須使用五大核心工具、遵守各車廠的客戶特殊要求、產品安全管理、製程稽核、防錯驗證和緊急應變計畫等。ISO 9001 適用所有產業，IATF 16949 只適用汽車供應鏈。

**Q2：車用五大核心工具是什麼？彼此有什麼關係？**

> 五大核心工具是 APQP、FMEA、MSA、SPC 和 PPAP。APQP 是新產品從規劃到量產的整體開發流程；在設計和製程開發階段用 FMEA 找出風險；在製程確認階段用 MSA 確認量測系統可信，再用 SPC 確認製程穩定、有能力；最後把這些證據整理成 PPAP 提交給客戶核准，才能正式量產。

**Q3：什麼情況需要重新提交 PPAP？**

> 新零件、設計變更、更換材料或供應商、更換製程或機台、搬遷工廠、模具重大修改，以及停產一段時間後再生產等。原則是只要可能影響產品品質的變更，都要通知客戶，並依客戶要求重新提交 PPAP。

**Q4：你怎麼推動持續改善？**

> 我會先用數據找出改善機會，例如用柏拉圖找出主要不良項目或品質成本最高的地方，再用 PDCA 或 DMAIC 的架構推動：定義問題和目標、分析根本原因、擬定並驗證對策，最後標準化並持續監控。也會鼓勵現場人員參與，例如透過提案制度或品管圈，因為最了解問題的通常是第一線的人。

**Q5：第一方、第二方、第三方稽核有什麼不同？**

> 第一方是公司內部稽核自己；第二方是客戶稽核供應商，或公司稽核自己的供應商；第三方是由獨立的驗證機構稽核，例如 ISO 9001 的認證稽核。
