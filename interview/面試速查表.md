## 必背公式

| 公式 | 內容 |
|---|---|
| Ca | (μ − M) / (T/2) |
| Cp | (USL − LSL) / 6σ |
| Cpk | min[(USL − μ), (μ − LSL)] / 3σ ＝ Cp × (1 − \|Ca\|) |
| σ（組內） | R̄ / d₂（n = 5 時 d₂ = 2.326） |
| X̄ 圖界限 | X̿ ± A₂R̄（n = 5 時 A₂ = 0.577） |
| R 圖上限 | D₄R̄（n = 5 時 D₄ = 2.114） |
| GRR | √(EV² + AV²)，**平方相加** |
| ndc | 1.41 × PV / GRR |
| RPN | S × O × D |
| DPPM | 不良數 ÷ 總數 × 1,000,000 |

## 一定會被問的「差異題」

| 比較 | 一句話分辨 |
|---|---|
| QC vs QA | 事後**檢驗**產品 vs 事前**預防**的系統 |
| 管制界限 vs 規格界限 | 製程的**聲音**（數據算出來）vs 客戶的**要求**（規定的） |
| 製程穩定 vs 有能力 | 可預測（管制圖）vs 符合規格（Cpk）；**先穩定再談能力** |
| Cp vs Cpk | 只看變異 vs 同時看中心與變異；Cp ≫ Cpk 代表**中心偏移** |
| Cpk vs Ppk | 組內 σ（短期潛在）vs 整體 σ（長期實際） |
| 共同原因 vs 特殊原因 | 系統本來就有，要改系統 vs 可找出排除 |
| 重複性 vs 再現性 | 同一人重複量（量具）vs 不同人量（人／方法） |
| 校正 vs MSA | 量具準不準 vs 整個量測系統能不能用 |
| 不良品 vs 缺點 | 1 支手機 3 道刮傷 = 1 個不良品、3 個缺點 |
| p 圖 vs np 圖 | 不良**率**（n 可變）vs 不良**數**（n 固定） |
| c 圖 vs u 圖 | 缺點數（單位固定）vs 單位缺點數（單位可變） |
| 105E vs 1916 | 用 AQL、Ac 可 > 0 vs 不用 AQL、**Ac = 0** |
| 發生原因 vs 流出原因 | 為什麼**產生**不良 vs 為什麼**沒抓到** |
| 圍堵 vs 永久對策 | 先止血（D3）vs 根治（D5） |
| D6 vs D7 | 解決**這一個**問題 vs 防止**同類**問題在別處發生 |
| DFMEA vs PFMEA | 設計的風險 vs 製程的風險 |
| 預防控制 vs 偵測控制 | 讓原因不發生（降 O）vs 發生了抓得到（降 D） |
| RPN vs AP | S×O×D 相乘 vs 查表、**嚴重度優先** |
| ISO 9001 vs IATF 16949 | 所有產業 vs 汽車業（加上核心工具、CSR 等） |

## 常見陷阱

- ❌ **AQL 0.65 = 允許 0.65% 不良** → AQL 是抽樣計畫的參數，客戶仍期望零不良
- ❌ **%EV + %AV = %GRR** → 平方相加：√(EV² + AV²)
- ❌ **點都在管制界限內就正常** → 還要看連續 9 點同側、連續 6 點上升等排列
- ❌ **點都集中在中心線附近很好** → 連續 15 點在 1σ 內是**異常**（界限算錯或數據有問題）
- ❌ **製程不穩定也能算 Cpk** → 先穩定才有意義
- ❌ **根本原因是作業員疏忽** → 要追問為什麼制度允許疏忽發生
- ❌ **對策只有教育訓練** → 優先防呆、自動偵測
- ❌ **改善製程能降低 S** → S 只能靠設計變更降低
- ❌ **校正合格就不用做 MSA** → MSA 評估的還包括人和方法

## 情境題萬用架構

> 「產線不良率突然升高」、「客戶抱怨」、「供應商來料異常」⋯⋯都可以用這個順序回答：

1. **確認問題**：什麼不良、多少、哪一批、哪條線（5W2H）
2. **圍堵**：隔離可疑品、追溯範圍、加嚴檢驗，**先保護客戶**
3. **找原因**：4M1E 檢查變更點；IS / IS NOT；用數據驗證
4. **對策**：發生原因與流出原因都要處理；優先防呆
5. **確認效果**：用數據證明
6. **標準化與水平展開**：更新 SOP、PFMEA、管制計畫

> 回答時加上一句「**我會先確認數據和量測系統是可信的**」，能展現品質工程師的專業思維。

## 反問面試官的問題

- 這個職位主要負責哪一段？（IQC、製程、客訴、供應商？）
- 目前最常遇到的品質問題是什麼？
- 公司導入了哪些品質系統？（ISO 9001、IATF 16949？）
- 使用哪些工具或軟體？（Minitab、SPC 系統、MES？）
- 新人的訓練方式？多久會開始獨立處理客訴或 8D？
