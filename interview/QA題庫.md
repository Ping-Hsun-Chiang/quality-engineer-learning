## 階段練習題（全部學完後再回答）

### 階段 1：品質基礎

- [ ] 客戶抱怨一批產品不良，第一時間由哪個職位（QE／SQE／CQE）處理？若查出是供應商來料問題，會轉由誰接手？
- [ ] 產線來了新作業員後不良率上升，這屬於 4M1E 的哪一項？在 PDCA 的 A（處置）階段應該做什麼，才能避免再發生？
- [ ] 「報廢」和「客戶退貨」分別屬於品質成本的哪一類？

### 階段 2：QC 七大手法

- [ ] 柏拉圖中，前兩項累積占 70%。如果資源只夠改善一項，你會怎麼決定先做哪一項？（提示：除了數量，還要考慮什麼？）
- [ ] 散佈圖顯示「作業員年資」和「不良率」強負相關，可以直接下結論「年資短的人比較容易做錯」嗎？為什麼？
- [ ] 某尺寸的直方圖右側像被刀切掉一樣（絕壁型），最可能的原因是什麼？這對計算 Cpk 有什麼影響？

### 階段 3：SPC 與製程能力

- [ ] 手算：規格 50 ± 0.5，X̿ = 49.8，R̄ = 0.4，n = 4（d₂ = 2.059）。求 σ、Ca、Cp、Cpk，並說明應該優先採取什麼對策。
- [ ] 每天檢驗的數量不同，要監控每天的不良率，應該用哪一種管制圖？如果改成每天固定抽 200 個呢？
- [ ] 管制圖上連續 7 點持續上升，但都還在管制界限內，也都在規格內。要不要處理？為什麼？
- [ ] 同一組數據算出 Cpk = 1.5、Ppk = 0.9，這代表什麼？

### 階段 3：MSA

- [ ] GR&R 結果：%EV = 25%、%AV = 5%、ndc = 3。請判定結果，並說明問題主要出在哪裡、要怎麼改善。
- [ ] 公差 ±0.02 mm，現場只有解析度 0.01 mm 的游標卡尺，可以用來做檢驗嗎？為什麼？
- [ ] 某量測系統 %GRR（對總變異）= 35%，但 %公差 = 8%。這個量測系統可以用嗎？要看用途是什麼？
- [ ] 做 GR&R 時，為什麼要挑涵蓋整個製程範圍的零件，而不是挑 10 個差不多的？

### 階段 3：抽樣檢驗與 AQL

- [ ] 查表：批量 N = 600，一般檢驗水準 II，AQL 1.0。樣本數、Ac、Re 各是多少？
- [ ] 查表：批量 N = 600，一般檢驗水準 II，AQL 0.40。遇到箭頭時，最後的樣本數和 Ac/Re 是多少？
- [ ] 某供應商在正常檢驗下，最近 5 批的結果為：允收、拒收、允收、允收、拒收。下一批應該用什麼檢驗方式？
- [ ] 客戶要求從 AQL 抽樣改成 C=0 抽樣，對供應商有什麼影響？供應商應該怎麼因應？

### 階段 4：8D

- [ ] 某批產品被客訴，你已經全檢挑選完庫存。這樣 D3 就完成了嗎？還有哪些地方要圍堵？
- [ ] 客訴原因是「作業員漏鎖一顆螺絲」。請分別寫出發生原因與流出原因，並提出比「教育訓練」更強的對策。
- [ ] 改善後不良率從 3% 降到 0.5%，可以直接結案嗎？D6 要怎麼證明對策有效？

### 階段 4：FMEA

- [ ] 請把以下內容分類成失效原因、失效模式、失效影響：「螺絲扭力不足」、「電動起子扭力設定錯誤」、「使用中外殼鬆脫」。
- [ ] 某項目 S = 9、O = 3、D = 3，RPN = 81，低於公司門檻 100，可以不處理嗎？
- [ ] 主管要求「把 RPN 降到 100 以下」，同事建議把 D 從 6 改成 4。你會怎麼回應？

### 階段 5：品質系統與持續改善

- [ ] 公司要把某零件的塑料換成另一家供應商的同等級材料，價格便宜 10%。如果客戶是車廠，在量產前要做哪些事？
- [ ] 客戶稽核時發現：PFMEA 寫「每批首件檢驗」，但管制計畫和現場的檢驗紀錄都沒有這一項。這是什麼問題？要怎麼改善？
- [ ] 請舉一個你身邊（工作、學校或生活）可以用 5S 或防呆改善的例子。
